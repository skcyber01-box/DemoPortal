# MOPH Certificate – Map V.1 (Web Demo)

ต้นแบบเว็บแผนที่สถานพยาบาลที่ออกใบรับรองแพทย์ดิจิทัล ตาม Req Map V.1 — ไฟล์เดียว (`index.html`) ไม่ต้อง build

## Deploy ขึ้น Vercel
**วิธีที่ 1 – GitHub (แนะนำ ใช้แบบเดียวกับ Demo Portal)**
1. สร้าง repo ใหม่ เช่น `moph-cert-map` แล้วอัปโหลด `index.html` ไว้ที่ root
2. Vercel → Add New → Project → Import repo นั้น
3. Framework Preset = **Other**, Build Command ว่าง, Output Directory ว่าง → Deploy

**วิธีที่ 2 – Vercel CLI**
```
npm i -g vercel
cd moph-cert-map-web_v001
vercel --prod
```

## สิ่งที่ทำได้ในเดโม
- หมุดแยกสี + ตัวอักษรตามระดับ (ศ ท ช สต อ ค), หมุดเส้นประ = Inactive, จุดเขียว/เทา = เปิด/ปิดตามเวลาทำการ
- กดหมุด → ชื่อ ระดับ Active/Inactive ใบรับรองที่ออกได้ ที่อยู่ วัน-เวลา เบอร์โทร (กดโทรได้) ระยะห่าง
- นำทาง (เปิด Google Maps), แชร์โลเคชัน (เมนูแชร์ของเครื่อง / คัดลอกลิงก์)
- ตัวกรอง: ประเภทใบรับรอง, เปิด/ปิด (อิงเวลาจริง หรือเวลาจำลอง ศ. 10:30), ระดับ, ซ่อน Inactive
- ค้นหาใกล้ฉัน (ขอสิทธิ์ตำแหน่งจริง) และปุ่ม "ค้นหาในบริเวณนี้" เมื่อเลื่อน/ซูมแผนที่
- ค้นหาด้วยคำที่ประชาชนใช้ เช่น "ต่อใบขับขี่" → ใบรับรองแพทย์สำหรับใบอนุญาตขับรถ
- เข้าสู่ระบบด้วย Health ID (จำลอง) → หน้าขอความยินยอม (PDPA)
- รองรับมือถือ (bottom sheet) และเดสก์ท็อป (แถบด้านซ้าย)

## หมายเหตุ
- ข้อมูลสถานพยาบาล ที่อยู่ และเบอร์โทรเป็น **ข้อมูลตัวอย่าง**; หากผู้ใช้อนุญาตตำแหน่งและอยู่ไกลจากจุดตัวอย่าง ระบบจะจัดวางข้อมูลตัวอย่างรอบตำแหน่งผู้ใช้
- แผนที่ฐานใช้ OpenStreetMap เพื่อการสาธิตเท่านั้น — ระบบจริงเปลี่ยนเป็น map provider ของบริษัทลูก
- ฟีเจอร์ระบุตำแหน่งต้องเปิดผ่าน HTTPS (Vercel เป็น HTTPS อยู่แล้ว)
- แก้ข้อมูลตัวอย่างได้ที่ตัวแปร `RAW` ใน `index.html`
